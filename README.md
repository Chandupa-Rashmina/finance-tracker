# 💰 Finance Tracker

A beautiful and powerful personal finance management app built with Flutter. Track your expenses, income, and financial goals with ease.

![Flutter](https://img.shields.io/badge/Flutter-3.19-blue)
![Dart](https://img.shields.io/badge/Dart-3.3-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Features

### ✅ Implemented Features
- **📊 Dashboard** - Real-time balance overview and monthly expense tracking
- **📈 Statistics & Charts** - Interactive charts for expense distribution and trends
- **📤 Data Export** - CSV export for transactions and monthly summaries
- **💾 Local Storage** - JSON database with full CRUD operations
- **🎨 Beautiful UI** - Material Design 3 with responsive layout

### 🚧 Upcoming Features
- **🏷️ Categories Management** - Custom categories with budgets and colors
- **📥 Data Import** - CSV import functionality
- **☁️ Cloud Sync** - Firebase backup and synchronization
- **🔔 Budget Alerts** - Notifications for spending limits
- **🌐 Multi-Currency** - Support for different currencies
- **📊 Advanced Reports** - PDF reports and yearly analytics

## 🚀 Getting Started

### Prerequisites
- Flutter SDK 3.19 or higher
- Dart 3.3 or higher
- Android/iOS development environment

### Installation
```bash
# Clone the repository
git clone https://github.com/Chandupa-Rashmina/finance-tracker.git

# Navigate to project
cd finance-tracker

# Install dependencies
flutter pub get

# Run the app
flutter run
